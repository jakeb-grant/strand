# The mutants (docs/eval.md, "Mutants"; docs/decisions.md eval-sandbox):
# each patch reverts a fix in the product's crates, and the regression
# scenario that reproduces its bug must pass on HEAD and fail under it
# with at least the checks listed. scripts/eval/mutants.sh runs them.
#
# <patch> <scenario, under eval/scenarios/> <expected failure>...
#   an expected failure is `check` (its status is FAIL), `check:#id`
#   (a failing finding of it names the node with that id) or
#   `check:#id:axis` (on that axis too).
#
# bug24-flip-open.patch: the reverse of ff92415c's crates/strand-render/src

# it extends that state. Since late-text-dip a text not shaped yet takes no
# room, or only its width, so bug24-flip-open.scn's first pass moves nothing
# and its mutant runs bug24-flip-open-min.scn, whose text has a minimum width.

# keeps its buffer's size (`laid_size`) and glide_moved its `unpainted` check
