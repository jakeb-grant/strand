# The mutants (docs/eval.md, "Mutants"; docs/decisions.md eval-sandbox):
# each patch reverts a fix in the product's crates, and the regression
# scenario that reproduces its bug must pass on HEAD and fail under it
# with at least the checks listed. scripts/eval/mutants.sh runs them.
#
# <patch> <scenario, under eval/scenarios/> <expected failure>...
#   an expected failure is `check` (its status is FAIL), `check:#id`
#   (a failing finding of it names the node with that id) or
#   `check:#id:axis` (on that axis too).
#
# bug24-flip-open.patch: the reverse of ff92415c's crates/strand-render/src
# hunks (flip-open; owner-testing.md bug 24), cut against this branch, with
# late-text-dip's keeping of unpainted nodes (still_shaping) taken out too:
# it extends that state. Since late-text-dip a text not shaped yet takes no
# room, or only its width, so bug24-flip-open.scn's first pass moves nothing
# and its mutant runs bug24-flip-open-min.scn, whose text has a minimum width.
# bug25-hidden-text.patch: the reverse of 2fab9622's two hidden_texts calls
# in node.rs (hidden-text; owner-testing.md bug 25), cut against this branch;
# the function stays, late-text-dip calls it for a box clipped to nothing.
# bug23-gpu-regions.patch: b293b8ef's fix (gpu-regions; owner-testing.md
# bug 23) reverted in what it does, cut against this branch:
# `State::sync_presented` keeps its signature (eval's surface leg calls it,
# as crates/strand's GPU host did) and does nothing, and that host's call
# is removed. The surface leg sees the first hunk (docs/eval.md, "Surface
# leg"): the island's presents keep its first frame's regions.
# popup-still-pose.patch: eval-r3's fix reverted (decisions.md eval-r3): a
# preview that finds an exit at its pose with nothing to move no longer
# leaves the surface wanting the frame that ends it, so the popup's card
# never unmounts and the popup stays mapped.
